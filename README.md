
# Password Complexity Checker

A beginner-level Python training assignment that checks password composition using basic security rules.

## Project Overview

This program evaluates a password based on its length and character types. It checks whether the password contains uppercase letters, lowercase letters, numbers, and special characters.

## Features

- Checks minimum password length of 8 characters
- Identifies uppercase and lowercase letters
- Checks for numeric digits
- Checks for special characters
- Displays basic password feedback

## Requirements

- Python 3.x
- No external libraries required

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/manideepbattu/Password-Complexity-Checker.git
   ```

2. Open the project folder:

   ```bash
   cd Password-Complexity-Checker
   ```

3. Run the Python program:

   ```bash
   python Password_Complexity_Checker.py
   ```

## Example

Input:
```text
Mani@123
```

Output:
```text
Strong password!
```

*The exact output depends on the program's evaluation rules.*

## Learning Outcomes

- Python conditional statements
- String handling
- Regular expressions
- Basic password security concepts

## Limitations

This program checks password composition rules only. It does not calculate password entropy, detect breached passwords, or determine resistance to real-world attacks.
